# Spaces / Presets（意识空间·定势组合资产）

**美术风格：写实空间**（拟真材质、光影、场景），营造沉浸感与"可回忆、熟悉"的氛围，
直接服务"意识/记忆投射空间"内核。对应 PRD §1.4、F-SPACE-* 与"定势组合（年代感/主题预制）"。

存放：写实场景的**定势组合（Preset Set）**预制——按年代感/主题打包的环境资产、光照预设、点缀元素。
客户端按服务端下发的"定势ID + 动态参数"在本地组装场景（见 TECH-P1 §4.2），服务端不传大资源。

> 占位目录。每个定势组合建议建独立子目录（如 `Presets/Retro90s/`、`Presets/Seaside/`）。
